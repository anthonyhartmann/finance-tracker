🏦 Plaid Link — Finance Tracker

  1. In Apps Script, run generateProdLinkToken() and copy the link token from the debug tab.
  2. Paste it below and click Connect your bank.
  3. Connect your bank(s) in the Plaid Link window. Each bank's public_token appears below instantly.
  4. When done, run exchangeProdPublicTokenManual() in Apps Script and paste each public_token.
Tip: you can also open this file with ?token=link-production-… appended to the URL. The token is remembered in this browser. If Link misbehaves from file://, serve this folder with python3 -m http.server 8000 and visit http://localhost:8000/plaid-link.html.

✅ Connected banks — copy these tokens

Paste each one into exchangeProdPublicTokenManual() in the Apps Script editor.
