Root cause chain (how a typo took down sync for 2 days)

  1. 0eae764 renamed loop variable date → dateStr in savings.backfill but missed two details.push(date + ...) calls — lines that only execute for qualifying transfer/Ally transactions.
  2. The commit's bundle.gs was hand-patched (3-line diff) while source changed 53 lines → git no longer represented production. The real rebuild stayed uncommitted in the working tree.
  3. esbuild doesn't type-check and jest runs ts-jest with diagnostics: false → "all 142 tests pass" despite tsc reporting Cannot find name 'date'.
  4. Existing backfill tests mocked zero qualifying transactions, so the broken lines never executed in tests.
  5. verify-gas-bundle.js only checks process.env / bare fetch( / syntax — it cannot catch undefined variables.
  6. No trigger watchdog: when the time triggers disappeared (most likely deleted during 07-26 incident response — onEdit proves the project itself was healthy), nothing noticed or recreated them.

What I changed (commit ea949d9, deployed)

  • Fix: date → dateStr in both details.push calls. A new regression test reproduces the exact production ReferenceError before the fix and passes after. 150/150 tests green, tsc --noEmit clean.
  • Gate: tsc --noEmit now runs before npm test, build:gas, verify:gas — this class of bug can no longer compile or deploy silently. Also fixed 6 latent instanceof type errors so the gate stays clean.
  • Resilience: scheduledRefresh now isolates savings.backfill failures — a backfill crash can no longer skip the dashboard refresh or fail the whole job.
  • Trigger self-healing: ensureTriggers is now idempotent (recreates exactly the 8:00 + 20:00 triggers) and, with a new listTriggers diagnostic, is exposed as a top-level GAS function so it can actually be run from the editor (previously it existed only on globalThis — invisible to the Run menu!).
  • Pipeline: new npm run deploy:gas = typecheck → build → bundle-verify → clasp push.
  • Docs: ts-app/AGENTS.md — architecture, deploy rules, debugging playbook, gotchas, this postmortem.
