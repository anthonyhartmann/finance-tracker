Security: Add Plaid webhook verification using Plaid-Verification header. Plaid publishes verification keys at https://cdn.plaid.com/verification/public-key.json. Verify HMAC-SHA256 of the request body.

Entry point: startWebhookServer(port?) — starts Express on configurable port (default 3001)

Execution order

Steps are sequential — each builds on the previous:

  1. Step 1 (Savings) — add transactionsGet to plaid, create savings module + tests
  2. Step 2 (Snapshot) — add sheet copy/delete/rename to sheet-api, create snapshot module + tests
  3. Step 3 (Webhook) — create Express webhook handler + tests

Estimated: ~30 min per step. All three in one session.

What we're NOT migrating

  • Link.gs interactive parts — SpreadsheetApp.getUi() prompts. In TS, user sets tokens via env vars or a simple CLI script. The token exchange logic is already in plaid/index.ts.
  • Setup.gs — One-time credential entry via UI prompts. TS uses .env file.
  • Toast messages — GAS-only UI notification. In TS, just log.
  • Time-driven triggers — Already replaced by webhooks.
